# Cognitrix v0.5.3

Covers PRs #80 to #87, merged since v0.5.2.

## Highlights

### A new look: one sidebar for the whole app
- One flat sidebar on every page replaces the top bar, the old nav sidebar and the chat page's own chat list. New chat and Search (Ctrl K, now also finds chats) sit at the top, then Dashboard, Inbox, Agents, Apps, Automations and Knowledge, with Tasks, Teams and Meetings under More.
- Every chat is listed with a Recent / By agent switch, pinned chats first and archived chats behind a toggle. The sidebar collapses to a rail of agent thumbnails with chat flyouts; on phones it is a drawer.
- Chats have a slim header, right-aligned bubbles for your messages, a floating composer, and a new-chat screen with a greeting, suggestions and your recent agents.

### Chat side panel
- A "This chat" panel (Ctrl+. / Cmd+.) shows the agent's live computer, approvals and questions waiting on you, the chat's artifacts and files, recent tool steps, working folders and chat details.
- Agents and teams get coloured thumbnails; pick a colour and an emoji on an agent's General tab.

### Steer a running chat
- Messages sent while an agent is working are no longer refused. They wait in the chat and the agent reads them after its current step. Send now, edit or remove a waiting message. Works in chat apps and between agents too.

### Custom themes
- Settings > Appearance has light and dark theme pickers with Signal, Nord, Solarized, Catppuccin, Tokyo Night and High contrast built in.
- Create your own theme with a live preview, or import a Codex app theme or a VS Code colour theme. Themes sync to your account across web and desktop.
- Each theme has hand-drawn artwork shown in the sidebar, on new chats and as a faint horizon behind chats. Agents can change the theme and even draw artwork with the new Set Theme tool.

### Apps
- Agents can build and publish live web apps with the new Publish App tool. Each publish is a version; a new version only goes live once it answers, and you can roll back.
- Apps sleep when idle and wake on visit, run in your sandboxed computer (or locally when it is off), and can be shared with people on the server. Apps can also call Cognitrix with their own API key.
- The Apps page replaces Artifacts in the sidebar, with Pages, Images and Docs as tabs.

### Agent cards
- A new Show Card tool lets agents reply with rich cards: big numbers, charts, tables and "Next steps" buttons that send your pick back to the agent. Chat apps get a text version with buttons.
- Approvals, questions and Inbox details now use one cleaner panel design.

### Smarter default assistant
- The default assistant now sizes up each request, does quick things itself and coordinates bigger work by planning and handing parts to other agents.
- New accounts can add a starter team of five specialists (Researcher, Coder, Writer, Reviewer, Analyst); existing accounts get an "Add starter team" button on the Agents page.

## Fixes
- Chats started by an agent now share the starting chat's working folders.
- Call Agent replies no longer include the helper's thinking.
- Task runs now know the agent's name and today's date; the date follows your timezone.
- Skills are listed for agents on the server, not only in the CLI.
- Ctrl+. closes an open artifact or computer view too.

## Known gaps
- The sandbox image must be rebuilt for Apps to run inside the sandboxed computer; that path is untested against real Docker. The live computer preview in the chat panel is also untested against a real sandbox.
- Cards are not yet native in Slack, Teams or Discord.
- A collapsed sidebar opens expanded once after updating (its saved setting was renamed).
