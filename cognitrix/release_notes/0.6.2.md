# Cognitrix v0.6.2

Covers PRs #152 to #156, merged since v0.6.1.

## Highlights

### Chill mode
- **/chill** is a second, calmer way to use the app: an almost empty page with one box (typing, the mic and hands-free live voice) that talks to your main assistant.
- Once there is something to show, the box floats at the bottom and the newest page, file, app screen or computer fills the window, with the reply as a caption and a rail to flip back through what the chat made. Cards the assistant shows (tables, charts, buttons) appear under the answer.
- A Chill / Full switch, a header button and Ctrl+Shift+. move between the modes with the open chat, and the app reopens in the mode you used last.

### Files agents make show up in chat
- Agents can share files with a new Share File tool. Each one shows as a preview card in the reply: image, video, audio with a waveform, PDF, sheet, document, archive or text.
- At the end of a turn Cognitrix also looks for files the turn made in the sandbox, on a paired PC or in the chat's folders. They go on an "N more files made" shelf, and when nothing was shared the likely results become cards.
- Clicking a card opens a viewer in the side panel (full screen on pages without one), with downloads, Download all as a zip, and a Files list in the chat side panel.

### Agents can show you their screen
- A new Show Screenshot tool lets an agent show you a picture of one window on its computer (the sandbox, or your own paired PC) as an image card in the chat. Agents use it only when you ask to see the screen or when the picture is the answer.

## Improvements
- **Smaller sandbox computer image.** Duplicate Node.js packages, download caches and an unused voice helper are gone, with every coding CLI still included.
- **README rewritten** to match the current app, with the right source install steps.

## Fixes
- A shared file named thumb.jpg is no longer overwritten by its own thumbnail.
- Excel previews work without extra packages installed.
- Files from a project's shared sandbox download correctly after the turn ends.
