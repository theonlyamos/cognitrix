# Cognitrix v0.5.0

## Highlights

### Run agents on your AI subscriptions
- Run agents on a ChatGPT Plus or Pro plan by signing in, no API key needed.
- Run agents on coding agent CLIs already signed in on your computer: Claude Code, Codex, Gemini CLI, Copilot CLI and OpenCode. They get the agent's Cognitrix tools, and a new "Ask first" permission level.
- Claude is now called through Anthropic's own API, with prompt caching to cut cost.

### Connected apps and memory
- Connected apps: sign in to GitHub, Google Workspace, Notion, Linear, Sentry and other hosted MCP servers from Settings, and set each tool to Allow, Ask or Off.
- Global memory: agents keep saved memories about you between chats, with a Memory page to review them.
- Incognito chats, and search across past chats.
- Knowledge base: document collections that agents can search and quote from.

### Agents that do more
- Agents can start new chats and talk with other agents.
- Computer use and browser use work for agents.
- Long tasks stay inside the model's context window, with compaction mid-turn, and cut-off replies continue.
- Generate Image works with an OpenAI key when there is no Google key.
- Import an agent from an exported file.

### Chat
- Rename, pin, archive, search, export, copy, edit and regenerate chats. Edit and regenerate keep a turn's uploads.
- Listen to a reply, or have every reply read aloud.
- Faster chat list.
- The shell asks for approval instead of refusing, with "allow all commands in this chat".

### People and accounts
- Settings > People for admins, with invitations.
- Password reset by email (needs `COGNITRIX_SMTP_*`), change password in Settings, and `cognitrix reset-password` on the command line.
- Settings > Usage shows tokens and estimated cost per day, model and agent.
- Export your data.

### Desktop and web app
- The desktop app stays signed in, reconnects to its engine, and can launch at startup.
- Desktop self-update (turns on once the release is signed, see `desktop/README.md`).
- Native notifications with a test button.
- Install the web app on your phone or desktop, with push notifications.
- Discord joins Telegram and Slack as a chat app.
- First translated screens: French and Spanish.

### Fixes and upkeep
- Docker runs the app as an unprivileged user. The data folder inside the container is now `/home/cognitrix/.cognitrix`; check any custom volume mounts.
- Security headers for the web app, and fixes to reset links, invitations and disabled accounts.
- Frontend tests run in CI.
