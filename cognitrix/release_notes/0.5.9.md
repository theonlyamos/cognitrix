# Cognitrix v0.5.9

Covers PRs #136 and #137, merged since v0.5.8.

## Fixes
- **Chats work again after upgrading.** 0.5.8 added new chat and agent settings without adding them to existing databases, so every chat failed to save on an upgraded install. The app now adds any missing column when it starts.

## Highlights

### Models
- Provider model lists refreshed: GPT-6.2 Sol (new OpenAI default) and Astra, Gemini 4 Neon, Qwen 4 Max on OpenRouter, and newer Gemini image models. Retired models are gone from the lists.
- **Coding agent CLIs everywhere**: Claude Code, Codex, Gemini CLI, Copilot CLI, OpenCode and Antigravity CLI can now be picked in first-run setup, the chat model picker and the action reviewer picker. Settings > Models and keys shows whether each is installed and how to install it.
