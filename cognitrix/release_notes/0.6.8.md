# Cognitrix v0.6.8

Covers PRs #205 to #212, merged since v0.6.7.

## Highlights

### Tailscale, built in
- **Private address.** Turn on Tailscale in **Settings › Tailscale** and your server gets a private https address that only the machines on your tailnet can open. Cognitrix signs in to Tailscale itself, so there is nothing else to install on the server.
- **Public door, webhooks only by default.** A public address through Tailscale Funnel can receive webhooks, and you can choose to also open public links and apps. Off means off: a door whose address is turned off answers nothing.
- **Sign in with Tailscale.** Each person can link their Tailscale login and then open Cognitrix from their tailnet without typing a password. It is off until an admin turns it on.
- **Share apps with your tailnet.** An app an agent built can be shared with named people on your tailnet, or with everyone on it. Guests can use the app but not change it.
- **Pair your PC over the tailnet.** A paired PC can reach the server at its tailnet address. Linking is approved at the PC itself, and the PC checks it is talking to the same server before it trusts a new address.
- **Agents' computers on your tailnet (Fly).** Each person's Fly computer can join the tailnet as a tagged machine, so a home server or the desktop app can reach it, and agents can reach the machines your tailnet policy opens to that tag. An admin picks whose computers join. Computers that stop qualifying are removed from the tailnet right away.
- **Devices agents may use.** Two new tools, **List Tailnet Devices** and **Run On Tailnet Device**, let an agent run one command on a machine you allowed, as a login name you allowed. A person approves every command; auto-approve never answers for it.

Tailscale has been tested with stand-in clients only. A real tailnet and a real Fly machine still need a live try. See `docs/tailscale.md`.

### Passkey sign-in
- Sign in with Windows Hello, Touch ID, your phone or a security key. Add and remove passkeys in **Settings › Sign-ins**.
- The desktop app hands the passkey step to your default browser and signs you in when it is done.

### Usage charts
- **Settings › Usage and limits** now charts tokens and cost by day. Switch between Tokens and Cost, and split the bars by type, model or agent.
- Use on a subscription plan shows what it would have cost at API prices, as an estimate.

### Apps can use your connected apps
- An app's server code can use the connected apps, saved sign-ins and secrets you allow on its new **Access** tab.
- Raw app links now work outside Cognitrix.

## Fixes
- **Google Meet:** agents no longer get stuck on "Joining". Waiting to be let in is no longer read as the call having ended, guests can join by name, and an agent waits while you sign in to Google and then goes back to the call.
- Agents' computers have sound and a microphone again after the sandbox restarts.
- Opening an Inbox alert dismisses it. Approvals and questions stay until answered.
- The Dashboard's tokens tile no longer shows a huge percentage after a quiet week.
