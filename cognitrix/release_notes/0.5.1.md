# Cognitrix v0.5.1

## Highlights

### A computer for your agents
- Sandboxed computer: agents can work on their own Linux desktop in a Docker container instead of your screen, one desktop per agent. Watch from the new Computer panel beside the chat, and Take over or Hand back at any time. Turn it on in Settings > Agent access > Agents' computer (needs Docker).
- Background computer use on Windows and Linux (X11): agents read and operate one app window at a time without moving your mouse or taking keyboard focus, and every action is checked afterwards. Approvals can be given once per app.

### Working together
- Shared agents: share an agent with named people or everyone, as Can use or Can edit.
- Personal skills in Settings > Skills, which admins can publish for everyone.
- Slack channel mentions answer in a thread, with read-only guest turns for other people.
- Microsoft Teams and WhatsApp join Telegram, Slack and Discord as chat apps.
- Meeting notes: a new Meetings page.

### Agents that check in
- Check-ins: give an agent a standing brief and a frequency, and it checks in by itself, read-only, and alerts you only when the brief says so.
- Offers: during a check-in an agent can offer to take on work it noticed, with Accept and Dismiss in the Inbox.
- Skills with review: "Save as skill" from a chat, and a Propose Skill tool; drafts wait for approval in the Inbox.
- Stop all on an agent stops its chats, task runs and check-ins.
- Two new tool levels: "Only when I ask" and "Hand off to me".
- Agents can list, read, start and cancel tasks.

### Connected apps
- Slack as a connected app, Gmail "Send email" and Google Calendar "Create and change events".
- Guided sign-in setup for Google, GitHub and Slack, with Check and Test buttons.
- Optional Composio support with your own key, tool search, and new-mail triggers.

### App
- A new Dashboard is the home screen after sign-in: what's waiting on you, what's running, upcoming automations, recent chats and usage.
- Approval requests reach you as notifications when you're not on the chat: in the Inbox, as Windows toasts and web push with Approve and Deny, and in Telegram, Slack and Discord.
- Voice input in the desktop Quick Ask window.
