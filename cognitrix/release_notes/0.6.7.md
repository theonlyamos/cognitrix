# Cognitrix v0.6.7

Covers PRs #195 to #203, merged since v0.6.6.

## Highlights

### Cognitrix CLI, rebuilt for real work
- The CLI and editor (ACP) chats now use **your main assistant**, with the same prompts, tools and access as the desktop app. Terminal runs show up as normal app chats.
- **Headless runs:** `cognitrix -p` takes `--output-format text|json|stream-json`, `--resume`, `--cwd`, `--max-turns`, `--timeout`, `--effort`, `--allowed-tools` / `--disallowed-tools`, `--append-system-prompt`, and reads the prompt from stdin with `-p -`. Exit codes tell scripts what happened.
- **Fully autonomous mode:** `--dangerously-skip-permissions` (also `--yolo` and `--dangerously-bypass-approvals-and-sandbox`) answers every approval for that run so `cognitrix -p` never blocks. Your saved settings are not changed, and live browser chats are never covered.
- **More folders:** `--add-dir` / `--add-read-dir`, plus `/add-dir` and `/dirs` in the shell. `--continue` keeps the folders you added.
- **MCP servers from the terminal:** `cognitrix mcp` adds, lists and removes servers, and `--mcp-config` loads servers for a single run.
- New `cognitrix keys` and `cognitrix sessions` subcommands, `--json` listings, `/voice` and `--audio` for talking to the shell, and `/new`, `/session`, `/exit`.

### Auto-approve everything
- Auto-approve is now saved on your account, so it works in the desktop app too, and it answers every approval, including the full shell, Coding Agent and Request Access. Turning it on shows a clear warning.
- It never takes over your screen on its own and never covers people using your public links or shared chats.

### Ask first for every coding agent CLI
- **Ask first** now works for Codex, Gemini CLI, Copilot CLI, OpenCode and Antigravity CLI, not just Claude Code. Each command the CLI wants to run shows an approval card in the chat.
- Calls only a person can approve now always show a card, instead of the agent waiting on "Waiting for command approval" with nothing to press.

### Select text to reply
- Select text in an agent's reply and press **Reply** to quote it in your next message, in both full and chill mode.

### Call Agent can share folders
- Your assistant can give the agent it calls (for example a coder) write access and commands in the folders it is working in. It can only share what it can already write.

## Fixes
- Answered question cards show each question with its answer right under it.
- Quick ask starts a new chat on every Alt+Space; follow-ups in an open window stay in the same chat.
- Quotes are kept when a send fails and dropped when you switch chats.
- "Allow all commands" stays a shell-only grant while still covering coding agent CLI commands.
- MCP servers started by a CLI run no longer keep it from exiting.
