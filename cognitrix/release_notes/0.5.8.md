# Cognitrix v0.5.8

Covers PRs #120 to #135, merged since v0.5.7.

## Highlights

### Projects
- **Projects**: group chats and tasks around shared instructions, folders, knowledge and memory, with a page to manage them (Projects in the main menu). Move a chat into a project from its menu.
- A project's **Changes** view rolls up every file its agents changed.
- **Always allow** on approval cards: allow a tool for an agent, or commands that start the same way on a computer, without being asked again.

### Your own PC
- **Pair your PC** so agents can work on its files, run commands, open apps and take on tasks there. You keep command approval, read-only folders and undo.
- **Sign in with a code**: sign in on a new device with a code from one that's already signed in, and link a PC the same way. Settings > Sign-ins lists each signed-in device and can sign out just one.

### Agents' computer (sandbox)
- Agents use their own sandboxed computer by default, each as its own Linux user, and browse there.
- Code runs in the sandbox by default. Your folders are copied in automatically, changes come back for review, and each agent gets a fair share of the machine.
- File tools and imports stay inside each agent's folders. Idle computers move to the new image on their own.

### Chats
- **File changes as diffs**: a "files changed" card at the end of a turn opens a side-by-side diff in the chat panel. Accept or reject each part.
- **Artifacts** are now the normal way agents deliver work, including task results. Comment on a spot with one click or the C key.
- Each reply shows when it was sent and how long it took. The chat side panel shows token stats.

### Agents and tasks
- **Watch a GitHub pull request**: agents get woken when a PR's checks, reviews or comments change.
- Results of tasks an agent created go back to that agent.
- **Proactive assistant** with a morning brief (Settings > Assistant), and **dream mode** to tidy memory (Settings > Memory > Tidy now).
- Tools in task runs now know which agent called them, as they do in chats.

### Languages
- Chat sharing, public links, task failure reasons, notifications and the other screens that were still English only are now in French and Spanish. A new test catches screen text that isn't set up for translation.
