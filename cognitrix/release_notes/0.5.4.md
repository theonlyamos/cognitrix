# Cognitrix v0.5.4

Covers PR #89, merged since v0.5.3.

## Highlights

### The agents' computer keeps itself up to date
- Cognitrix now checks for a newer version of the sandboxed computer every 6 hours in the background, downloading only what changed. Set `COGNITRIX_SANDBOX_UPDATE_CHECK_HOURS` to change how often, or `0` to turn it off.
- A stopped computer starts on the newer version next time. A running one shows **Update** in the Computer panel, which restarts it; open windows close, but files and logins stay, and each agent's desktop comes back.

## Upgrading from 0.5.3 or earlier
- This is the release that picks up the sandbox changes from v0.5.2 (Chromium fills the screen, no warning bar) and v0.5.3 (Apps can run inside the sandbox). After updating, open the Computer panel and press **Update** if it shows, or simply let it pick up the new version the next time the computer starts.
- Don't use Reset for this: Reset also erases the computer's files and logins.

## Known gaps
- Untested on Docker Desktop for Windows and macOS; tested on Linux Docker.
