# Cognitrix v0.5.6

Covers PRs #95 to #117, merged since v0.5.5.

## Highlights

### Apps
- App code now lives in `~/.cognitrix/apps/<name>`. Every agent can read and write there without prompts (shell commands still ask), and older apps are copied in at startup. A built-in **build-app** skill guides agents through making one. Deleting an app now asks in an in-app dialog.
- **Check App**: agents take a screenshot of their app and see its errors and logs, using a headless Edge or Chrome when one is installed.
- **Test App**: agents write click-through tests (click, fill, expect...) that run on a throwaway copy of the live version. Passing tests are saved with the app and can be re-run.

### Agents' computer (sandbox)
- Agents can run and test code on their own computer: a sandbox shell, a per-agent workspace, a folder copied in with changes coming back as a reviewable diff, coding CLIs inside, and a test results card. Sandbox environment variables and sign-ins are set in Settings > Computer.
- **Hidden keys**: API keys and saved sign-ins reach the sandbox as placeholders and are swapped in only for approved sites, so the agent never sees them.
- **Snapshots**: save and restore the whole computer or one agent's setup, and copy an agent's setup to another agent.
- **Teach a task**: record yourself doing a task on the agent's desktop and turn it into a personal skill.
- **Host the computer on Fly** (`COGNITRIX_COMPUTER_SANDBOX=fly`): one machine per person that stops when idle and wakes on use. Setup in `docs/sandbox-on-fly.md`.
- **Live meetings**: agents join Google Meet, Teams and Zoom calls from the sandbox browser, take notes, and answer when named. Upcoming calls from a connected Google Calendar can be suggested 15 minutes before.
- **Payments**: agents can pay at a checkout only after you approve each payment in the app (off by default).

### Teams of agents
- **Agent swarms**: a lead agent spawns parallel workers and gets one combined report. Limits in Settings > Swarms; tasks can "Run as a swarm"; @all in group chats answers in parallel.
- **Agent email**: each agent gets an email address on a mailbox you bring (IMAP + SMTP), and mail from allowed senders starts work. Approve or deny by replying.
- **SMS**: text an agent through a Twilio number.

### Chats
- **Live voice mode**: talk with an agent hands-free, including spoken approvals (risky actions need "approve" or "allow").
- **Side questions** (Ctrl+/): ask about a chat without interrupting the running turn.
- **Share a chat** with people as Can read or Can write.
- **Public agent link** with a chat page and a website chat widget (Agent page > Sharing). Visitors get read-only guest turns.
- Connected apps that ship their own screens (MCP Apps) now open beside the chat.
- **Sheets and whiteboards** that people and agents both edit, under Apps > Sheets & boards.

### Knowledge and memory
- Add web pages or a site section to Knowledge, with scheduled refresh. Agents get a Learn From Website tool.
- Memory can ask before saving, holds saves made after reading web pages or files as proposals, and can be imported and exported. Tasks can opt in to reading memory.

### Admin
- **Spending caps** per person (monthly dollars and/or tokens), with an 80% alert, in Settings > People.
- **Audit log** of tool calls, sign-ins and admin changes (Settings > Audit log, kept 90 days by default).
- **Remove people**: their shared work moves to the admin, private data is deleted.

### Saving tokens and editors
- **Code mode** and **tools on demand** (agent Tools tab > Saving tokens): the agent writes short scripts that call tools, or loads tool details only when needed.
- `cognitrix acp` runs Cognitrix as an Agent Client Protocol server for editors such as Zed and JetBrains.

### Everything else
- **What's new** window after each update (this one), with a button to add missing starter agents.
- Every screen is now in French and Spanish.
- Antigravity CLI (agy) can run agents and the Coding Agent tool, and is installed in the sandbox.
- Sidebar: Knowledge and Automations moved into More; Tasks moved out of it.
- Model lists refreshed (Gemini 4 Hydrogen, GPT-6 Astra, Qwen 3.8 and more); retired models removed.
- Folder browser on the web app, OpenAI realtime voice for read-aloud, an Intel Mac desktop build, and optional code signing in CI.

## Upgrading from 0.5.5
- New Python dependencies (`mini-racer`, `agent-client-protocol`) install with the package.
- The engine pulls the newest sandbox image within 6 hours; use **Update** in the computer panel to get it now. Sandbox coding, hidden keys, Teach a task, live meetings and Test App need the new image.
- Spending caps, the audit log and the new channels are off until set up.

## Known gaps
- Not tested on real accounts or services: Fly hosting, live meeting calls, real checkouts, Gmail/Twilio for agent email and SMS, Zed/JetBrains over ACP, third-party MCP Apps.
- Not tested on a real Windows desktop build: code mode, the Apps folder for coding CLIs, and the new screens. Code signing waits on certificates.
- agy may not load the Cognitrix tools it is lent; the engine log warns when it doesn't.
