# Cognitrix v0.6.1

Covers PRs #143 to #150, merged since v0.6.0.

## Highlights

### Agents learn from finished work
- **Nightly chat review.** Each night, just before the memory tidy-up, finished chats and completed task runs are read once. Lasting facts become memories, a completed job becomes a personal skill (the direct way to do it, without the dead ends), and reference material goes into a "Learned from work" knowledge collection for the agent that did the work. An existing skill that covers the job is improved instead of copied.
- Busy, incognito, public-link and short chats are skipped. Settings › Memory has a nightly switch, Review now, and a list of what was kept with Remove and Undo.

### Memory backup to Notion
- After every tidy-up, your memories and About you summary are saved to one "Cognitrix memory backup" page in your Notion, updated rather than duplicated.
- Settings › Memory gets a Back up to Notion section with its status, Back up now and Restore from Notion. Connecting Notion on a fresh install offers the backup in the Inbox.
- Secret-looking notes are left out, and a fresh install never overwrites a bigger backup.

### Pull requests are watched automatically
- When an agent opens a GitHub pull request in any chat or task run (a create pull request tool, `gh pr create`, or a coding agent saying it opened one), the chat or task now watches it for reviews, comments and checks without being asked.
- On by default, with an off switch in Tasks › Watched PRs and per project. Project pages get a Pull requests tab.

### Find Tools and Run Code on for every agent
- Loading tools on demand and Run Code are now on by default for new and existing agents. Turning either off on the agent page sticks.

### Ask To Take Over works as intended
- An agent asking you to take over its computer now waits until you take over and hand back (up to 30 minutes). The chat shows a Take over / Skip card, and Take over opens the agent's computer with you in control.
- This request always asks you; permission levels and the action reviewer no longer answer it.

## Fixes
- **Links in chat open in your browser** in the desktop app. Links in replies, task results, team chat, pages and apps used to do nothing when clicked.
- **The sandboxed computer updates again.** A slow download of the computer image is no longer cut off after 30 minutes, a failed check retries after 20 minutes instead of 6 hours, the check also runs while the computer is stopped, and failures show up in the log.
- Every theme an agent makes or sets gets fitting artwork, and a broken drawing no longer loses the theme.
- Guest and public-link chats can use Search Knowledge and web search again.
