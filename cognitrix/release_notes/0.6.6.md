# Cognitrix v0.6.6

Covers PRs #191 to #193, merged since v0.6.5.

## Highlights

### Skills backed up to Notion
- Your skills, including the ones the chat review writes, are saved to a **Cognitrix skills backup** page in Notion after a review that changed them and after each memory tidy.
- **Back up now** and **Restore from Notion** in Settings > Memory now cover memories and skills together. Connecting Notion on a fresh install offers to restore your skills too.

### Chat review reads every finished chat
- The chat review no longer stops at 10 chats a run. It reads everything finished since the last run, oldest first.
- Nightly runs stop at the proactive token limit or after 90 minutes, and Settings > Memory shows progress like "Reading 12 of 40".

### Memory tidy merges memories on the same subject
- Tidy now groups memories about one subject and merges them into one, keeping every detail. Merges of agent-saved memories apply on their own only when names, numbers and key words survive; otherwise they show as suggestions.
- Saving a memory skips facts that are already saved in full, and grows an agent's existing memory in place when a fuller version comes in.
- Memories use short ids, so they take less room in agents' prompts.

## Fixes
- Quick ask: answer cards never showed because the window couldn't grow past the pill. Fixed.
- Quick ask: after its chat was deleted, every question failed until a restart. It now starts a new chat.
- Quick ask stays in voice mode when speech-to-text isn't set up, with a **Set up voice** button, and the mic button always shows in keyboard mode.
- Restoring skills no longer breaks the skills page when storage runs out, and Back up now with no skills is no longer shown as a failure.
