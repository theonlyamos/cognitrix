# Cognitrix v0.5.5

Covers PRs #91, #92 and #93, merged since v0.5.4.

## Highlights

### Apps open in their own window
- **Open** on an app's page now opens it in a window of its own: a new window in the desktop app, a new tab on the web. The window has a **Close** bar, and Esc closes it.
- Full screen (and an app's shared link) shows the app under a thin bar with **Back to Apps**; Esc goes back too.
- The back arrow on an app's page is no longer hidden under the menu on phones.

### A tidier chat input bar, with a model picker
- Every control in the chat box's bottom row now has one consistent look. Folders collapse into one button (for example "frontend +2") that opens the folder list; reasoning shows only when it isn't the default; auto-approve and incognito are small tinted icons. On phones only icons show.
- New **provider and model picker** in the input bar: switch the model for a chat without changing the saved agent. The choice is remembered per chat in your browser. Helper agents and the action reviewer keep their own models. Hidden for agents that run on a coding agent CLI.

### Chats agents start show up in the sidebar right away
- A chat one agent starts with another (Start Chat) now appears in the sidebar within a few seconds, without a reload. This also covers chats from chat apps and other tabs.
- **Call Agent** now saves its helper's work as a chat in your list, so you can see what the helper did. Calls from incognito chats and API-key callers stay unsaved, as before.

### Theme drawings are kept
- Every theme drawing is now saved in a drawing library, so picking other artwork in Settings no longer loses an agent-made drawing. The artwork picker lists saved drawings and can remove unused ones. The Set Theme agent tool can list and reuse saved drawings.
- The chat backdrop now shows the whole drawing, faintly, behind chat messages instead of a cropped strip at the bottom.

## Upgrading from 0.5.4
- No steps needed. Existing theme drawings are added to the new drawing library automatically.

## Known gaps
- The app window and model picker were not tested on a real Windows desktop build before release.
