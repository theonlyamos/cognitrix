# Cognitrix v0.6.0

Covers PRs #138, #139 and #140, merged since v0.5.9.

## Highlights

### A simpler app
- **Fewer places.** Navigation is now Home, Agents, Projects, Library and Tasks, with Meetings and Payments under More. Teams is a tab on Agents, Automations is the Scheduled filter on Tasks, Knowledge is a tab in Library and Notifications is the Recent tab of Inbox. Settings goes from 18 sections to 13, and agent pages from nine tabs to five (Overview, Setup, Access, Work, Sharing). Old links redirect.
- **Plain words.** Statuses, schedules, times, model names and costs read as words ("Running", "Weekdays at 9:00", "Took 2 min · about $0.04"). Artifacts are now Pages, swarms are Helpers and dream mode is Nightly tidy-up. French and Spanish are filled in.
- **Ctrl K finds more:** projects, pages, apps, knowledge, memories and settings sections.

### Chat
- **Team chat on the main chat screen**, with voice typing, a Mention button, approval cards and "Ask <name>" starters.
- **Files in team chats.** Attach pictures and documents with the paperclip, drag and drop, or paste. Every agent that answers sees them.
- Chats get a short title after the first reply, and chats in a project show the project's name in the sidebar.
- A lighter message box on phones: model, computer, folders and live voice move into the + sheet.
- A chat keeps its address, so a link to `/chat/<id>` opens it.

### AGENTS.md in every chat
- Every chat, task run and CLI turn now follows the AGENTS.md (or AGENTS.override.md, CLAUDE.md, .cursorrules) files of its working folders, from the repo root down, the way Codex does. Subfolders with their own file are picked up the first time a chat reads or changes a file there. Paired PCs and sandbox runs are covered too.
- The folder picker shows "Follows AGENTS.md" under each folder.

### Creating and reading work
- **New task from a sentence:** one box for what should get done, who does it and when, with schedules picked in words and kept in your time zone.
- **New agent from a sentence:** templates, a line on what it is for, and abilities in words. Agents with many tools load them on demand.
- **Task pages lead with the result**, with the steps folded under "How it got there".
- **Library thumbnails** draw the page itself, and each knowledge collection lists the agents and projects that read it.

## Fixes
- **The morning brief works again.** Check-ins can use Find Tools and Run Code (still read-only), Publish Brief accepts its list of items, and a brief run that publishes nothing now shows as failed instead of completed.
- Deleting or clearing a chat with an attached document works on the first try.
- A new agent starts on the main assistant's provider and model instead of Gemini.
- `<think>` text stays hidden while a reply streams, and a chat shows one card per page instead of one per version.
- The page toolbar fits the chat panel on 1280 to 1440 wide screens.
- Payments starts off, with limits and the card form shown only once it is on.
