# Cognitrix v0.5.2

Covers PRs #74 to #78, merged since v0.5.1.

## Highlights

### Artifacts
- Agents can publish pages (HTML or Markdown) that open beside the chat, with an Expand button.
- Share a page with a public link (on by default; turn off with `COGNITRIX_ARTIFACT_PUBLIC_LINKS=off`).
- Comment on a page and send the comment to the agent, which picks it up and replies or updates the page.
- Pages can ask for extra powers (ask the agent, keep data, offer downloads, read from connected apps), each with per-viewer consent.
- A new Artifacts page lists published pages along with images and documents agents generated. Pin pages to the Dashboard.

### Chat
- The chat list is grouped by agent and team, in collapsible sections with pinned chats on top. Team chats can now be renamed, pinned and archived.
- The composer is simpler: attach, run as task, auto-approve, incognito and reasoning level sit behind a + menu, and working-folder chips sit above the input.
- New chats no longer start with the app's working folder attached. Folders you set on an agent still apply.
- A new account menu at the bottom of the sidebar holds Settings, API Keys, theme (Light, Dark, System) and Sign out.

### Sandboxed computer
- The sandbox screen fills the panel instead of sitting off-center, and the panel can expand to the full app window or go full screen (Esc exits).

## Fixes
- Task runs no longer fail with "Task execution failed." for agents that have the Http Request tool.
- Standing check-ins skip the quality gate and are told the current local time.

## Known gaps
- Artifacts are untested in the desktop app and when shared to Slack or Telegram; new Artifacts screens are English only.
- The sandbox image must be rebuilt for the screen-fill and warning-bar fixes to take effect.
