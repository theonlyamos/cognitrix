# Cognitrix v0.5.7

Covers PR #119, merged since v0.5.6.

## Highlights

### Fixes
- **Agents can schedule work for themselves.** Asking an agent for something recurring, like "check my PRs every 15 minutes", used to fail with "Starting or scheduling a task requires an owner". The agent would then wrongly ask you to sign in. A task the agent starts or schedules without naming who runs it is now assigned to that agent. The error that remains says which agent is missing, not that you need to sign in.
- **Run Code keeps your account.** Tools an agent called from Run Code (code mode) ran without your account details, so a task created there was saved with no owner, and API key limits didn't apply inside scripts. Each call now runs as you, the same as a direct tool call.
- Retrying a failed tool call with corrected inputs no longer crashes on tools that receive the calling agent.
