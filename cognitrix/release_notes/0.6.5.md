# Cognitrix v0.6.5

Covers PRs #174 to #189, merged since v0.6.4.

## Highlights

### Agents no longer get cut off part-way
- Tool calls are no longer limited by default: no cap on tool rounds, calls running at once or Run Code calls. A positive setting still caps them.
- Tool slots are now per agent and chat instead of four for the whole server, and tools that wait on other agents (Call Agent, Spawn Workers, swarms, the board) no longer hold a slot, so agents can't deadlock each other.
- Each tool call has a time limit (15 minutes by default, `COGNITRIX_TOOL_TIMEOUT`), so a hung tool ends instead of leaving the chat stuck.
- Limits that stopped agents early were lifted: background chat turns have no time limit by default, tool results keep up to 32,000 characters, replies can use up to 32,000 output tokens on current models, MCP tools get the full tool time limit, task steps get 60 minutes, old chat messages are no longer dropped, skills follow the tool-round setting, and paired PC calls get 15 minutes. API routes keep their 5-minute limit.
- The chat shows "Still working…" when an agent goes quiet, and reasoning appears as an expandable **Thinking** block.

### Voice-first quick ask
- Alt+Space now opens quick ask listening: a pill docked at the bottom of the screen with a live waveform. Stop talking for a second and it sends.
- Answers show as cards above the pill, and follow-ups stack on top. Press Tab or start typing to switch to the keyboard; your last mode is remembered.

### Question cards
- Agents can ask up to four questions at once in one card, one at a time with Back and Next, with multiple choice, "Something else", Skip and their recommended answer picked already.
- Your answers stay in the chat as a summary, and typing in the chat box answers an open card. Agents are told to use the card rather than asking in plain text.

### Agents can ask for tools and connected apps
- An agent without a tool or connected app it needs can show a **Request Access** card. Allow it for this chat, add it to the agent, connect the app from the card, or deny.

### Design drafts
- A new **design-drafts** skill has agents draw two or three distinct options on one comparison page, in light and dark and at phone and desktop width, recommend one and ask which to build.
- New **Check Artifact** tool lets agents screenshot their own artifacts. A **Designer** joins the starter team.

### Every agent-built app gets an icon
- Apps use their own icon file when they have one, or a generated initials tile. The icon shows on the Apps pages and on installed desktop shortcuts. Change it or go back to initials from the app's page.
- A new **app-icon** skill covers native and mobile apps, and Generate Image can save straight into an app's folder.

## Improvements
- **Call Agent hand-off:** agents can hand a job to another agent and carry on, with the helper's report posted back to the chat when it's done. Waiting now has a time limit (10 minutes by default, up to 30).
- **Agents can find and control the Cognitrix app itself.** Every action in the app asks you first, auto-approve and "always allow" don't cover it, and agents can't act while an approval or question card is open.
- **Fast mode** switch for Claude Code and Codex agents, in the chat box and on the agent page. The Claude Code model list now shows full current model names.
- Chat box row: effort and fast now sit right after the agent and model, and auto-approve has a new shield-off icon.
- The folder button in the chat box is icon only until a folder is picked.

## Fixes
- Settings: the Advanced section showed a raw label, and text fields had tall gaps above them.
- Chats in the collapsed sidebar's agent flyout couldn't be clicked on chat pages.
- The agent cursor and Stop pill could stay on screen on Windows.
- Quick ask closes the mic when the window hides.
- The "Use initials" icon choice is kept across restarts.
