# Cognitrix v0.6.4

Covers PRs #166 to #172, merged since v0.6.3.

## Highlights

### Set everything up in Settings, not environment variables
- App-wide settings now live in **Settings** and are saved in the data folder, with secrets encrypted: email sending, the GitHub App, cloud computers on Fly, web search keys, model provider addresses and keys, OAuth clients, push alerts, safety, sharing, limits and timeouts.
- A new **Server setup** page appears on first start of a server with no accounts. Pick SQLite, PostgreSQL, MySQL or MongoDB and the built-in queue or Redis. The database sign-in and queue address are checked before saving.
- The sign-in key and secrets key are made on first start and kept in the data folder. Keys an older setup set as `JWT_SECRET_KEY` / `COGNITRIX_SECRETS_KEY` are copied there once, so saved secrets and sign-ins keep working; after that the variables can go.
- Database, job queue, allowed API addresses and the content security policy are under **Settings > Advanced**. Servers without a browser can use `cognitrix settings list/set/unset`.
- **Heads-up:** values in the environment or `.env` are no longer read for these settings and are not imported (only the two keys above are copied once). Re-enter provider keys and other settings in Settings after updating. `.env.example` is gone; README, compose and fly.toml are updated.

### Chats carry on after a restart
- Chat turns are saved after every tool round. If the engine stops mid-reply, the turn is picked up where it left off: tools that were running get an "interrupted" result and the same agent carries on, without a new message from you.
- This happens at most twice per turn and within six hours; otherwise you get an Inbox alert. Turn it off in **Settings > Advanced > Restarts**.

### "Done when" for tasks
- Tasks can have an optional **Done when**. Planning, steps and the final answer see it, and a separate reviewer checks the result against it.
- A result that falls short goes back to the lead agent with the reviewer's notes (up to 2 fix rounds, configurable). The task page shows how the result did. Agents can set it with Create Task and Update Task.

### Message board upgrades
- **@name tags**, nudges for unanswered questions, cards in chat, search, an already-asked check, and edit or withdraw for your posts.
- **Project channels** with task threads, claim and wait, people, scheduled posts and `/commands`.
- Outside agents can join with the **board CLI**, with grants controlling what they can do. Boards can mirror to **Slack**.
- Decisions are saved to memory, pages update live, the morning brief gets a board section, and large boards page smoothly.

### Install agent-built Apps as desktop apps
- **Install as app** on an app's page (desktop app) adds a shortcut that opens the app in its own window: Start menu (and optionally desktop) on Windows, `~/Applications/Cognitrix Apps` on macOS, a `.desktop` entry on Linux.
- Installed apps can show notifications, put an icon in the tray and use your connected apps. Each of these asks you first, and changes to connected apps ask every time.
- Uninstall from the app's page, **Settings > Desktop app**, or the app window.

## Improvements
- **Google Workspace:** new Google Chat (read, with an option to send), Contacts and Search all of Google connections, plus Google Classroom behind an admin setting. Gmail label tools now work, and calendar changes use Google's own Calendar tools. The setup guide lists the new APIs and notes that older OAuth clients need the AI-powered agent tick.
- Switching to chill mode from the Home page (or Ctrl+Shift+. outside a chat) now starts a fresh chat. Switching from inside a chat still keeps that chat.

## Fixes
- A web server and worker starting together can no longer end up with different keys.
- Saving Fly or computer settings applies the new token, app and region without a restart.
